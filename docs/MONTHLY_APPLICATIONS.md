# 월별 신청 통계

운영자 콘솔 → **신청 현황** → **홈스테이** 또는 **자원봉사자** → **월별 신청**에서 확인합니다. 기존 일반 운영자 이상 권한으로 사용할 수 있습니다.

- 연도를 선택해 1월부터 12월까지 신규 신청 수를 그래프와 표로 확인합니다. 신청이 없는 달도 0으로 표시합니다.
- 홈스테이는 신청 1건을 1가정, 자원봉사는 신청 1건을 1명으로 집계합니다. 가족 구성원 수나 순례자 수용 인원과 다른 지표입니다.
- 최초 시스템 접수일(`createdAt`)을 한국 시간으로 변환해 월을 정합니다. 이후 수정·승인·취소일로 접수 월이 바뀌지 않습니다. 종이 신청은 시스템에 등록한 날 기준입니다.
- 신규 신청은 취소 포함 전체 접수 수입니다. 현재 유효 신청과 현재 취소 신청은 같은 접수 월의 기록을 현재 상태로 나눈 값입니다. 취소가 발생한 월별 건수를 뜻하지 않습니다.
- 전월 대비 증감과 증감률은 신규 신청 수를 비교합니다. 1월은 이전 해 12월과 비교하고, 전월이 0이면 증감률 대신 '비교 기준 없음'을 표시합니다.
- 이번 달은 집계 중이므로 지난달 전체와 기간 길이가 다릅니다. 미래 달은 '미도래'로 표시합니다.
- 목록 검색·상태·언어·구역 등의 필터와 무관하게 전체 저장된 신청을 집계합니다.
- **통계 CSV**로 선택한 연도의 월별 집계를 다운로드할 수 있습니다. 개인 정보는 포함되지 않습니다.

월별 접수 증가는 홍보 전후의 신청 추이를 파악하는 자료입니다. 특정 홍보 활동의 직접적인 효과를 판단하려면 홍보 실시 시기·대상 등을 함께 확인해야 합니다.

검증은 `npm run typecheck`, `npm test`, `npm run build`로 수행합니다. 집계 테스트는 한국 시간의 월·연도 경계, 취소 분리, 최초 접수 월 유지와 빈 자료를 확인합니다.
