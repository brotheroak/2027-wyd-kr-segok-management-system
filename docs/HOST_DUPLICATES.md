# 홈스테이 중복 접수 기준

온라인 신청과 운영자의 종이 신청 등록은 동일한 최종 저장 검사를 거칩니다.
취소 상태가 아닌 기존 신청 중 다음 하나에 해당하면 신규 등록을 거부합니다.

- 전화번호가 동일합니다. 구분 기호 및 한국 국가번호(+82)를 정리해 비교합니다.
- 성명, 기본 주소, 상세 주소가 모두 동일합니다. 공백과 영문 대소문자, 전각 문자 차이를 정리해 비교합니다.

성명 또는 성명·세례명만 일치하는 것은 차단 근거로 사용하지 않습니다.
전화번호가 같으면 다른 주소라도 신규 접수가 차단되므로, 별도 가정을 추가할 필요가 있다면 담당자 확인이 필요합니다.
다른 전화번호와 다른 상세 주소를 사용하는 동명이인은 허용합니다.
도로명과 지번 주소 간 변환, 약칭 및 오타의 의미상 동일성은 판별하지 않습니다.

신청 화면 사전 검사와 최종 저장은 같은 비교 함수를 사용합니다.
PostgreSQL 신규 등록은 트랜잭션 잠금 안에서 검사하고 저장합니다.
기존 신청 수정은 이 신규 등록 검사 대상이 아닙니다.
기존 중복 건을 일괄 삭제하거나 병합하지 않습니다.
중복 시 신청자에게 기존 접수 조회를 안내하며 담당자 이메일 자동 알림은 구현하지 않았습니다.
